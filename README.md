# X 修仙 · 创作者洞府

把 X 创作者数据整理成一座可拖动的修仙洞府：每日发推与回推任务、撰写提醒、工作室曝光、粉丝变化和原创内容奖励进度，一屏查看。

当前版本 **0.1.8**，使用 Chrome Manifest V3，要求 **Chrome 116+**。墨绿、青玉与淡金配色，山水横幅与账号头像叠层，收起后显示圆角方形刀剑 X。

![山水横幅](extension/assets/mountain-banner-restored.png)

## 功能

| 模块 | 能力 |
| --- | --- |
| 悬浮洞府 | 自由拖动并记住位置；收起为 56px 图标；读取当前账号头像、昵称和 @ID |
| 每日修行 | 设置发推、回推目标；发布成功立即计数，后台按工作室数据校正；回复成功在原按钮上淡入淡出绿色 `+1` |
| 撰写功法 | 距上次发推的时间、可设置的倒计时；到时持续提醒，支持去撰写、稍后 15 分钟与确认 |
| 天地灵气 | 工作室当天 Impressions 总曝光 |
| 道侣 | 粉丝总数和当天首次观测后的净变化 |
| 飞升进度 | 近 90 天认证用户主页曝光的 50W 总进度条，记录每日净增与每次数值变化 |
| 修行日志 | 每日任务、曝光、粉丝与奖励进度历史；日期筛选与 JSON 导出 |

首页自动适应可用高度，日志与设置在内容区滚动。计数静默更新，提醒浮层不挤压面板布局。

## 安装与使用

1. 下载仓库或执行 `git clone https://github.com/zkilxx/x-xiuxian.git`。
2. Chrome 打开 `chrome://extensions`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本项目的 **`extension/`** 目录。
4. 刷新已登录的 X 页面，展开悬浮洞府，在「功法」中设置任务目标与提醒间隔。

可直接加载仓库内的构建文件，无需先安装 npm 依赖。更新代码后，在扩展管理页重新加载插件，再刷新 X。

正常使用时不需要手动打开数据页。插件默认每 5 分钟依次读取：

```text
原创内容奖励 → 工作室分析（发布数、回推数、曝光）→ 粉丝资料
```

读取使用未激活的临时后台标签，不切换当前标签，完成后关闭插件创建的临时标签。底部「同步」可提前触发同一流程，状态显示整轮结果；部分失败时保留已有数据并说明待读取。

## 数据口径

**每日修行与曝光**

- 发推数采用工作室 `TweetCreate + QuoteCreate`，回推数采用 `ReplyCreate`；转帖不计。`Reply` 表示收到的回复，不作为自己发布的回推数。
- 本地发布事件只在 X 确认成功后计数，按帖子 ID 去重；失败、取消不计数。启用插件前或其他设备的发布，由工作室今日统计补齐。
- 工作室数据用于校正总数，不与本地总数直接相加。最近 10 分钟的新发布暂时保留，等待官方统计追上；没有待确认事件时也接受官方向下校正。
- 发布统计与曝光沿用工作室的 **UTC 日期**。历史日数据与近期回填去重；空响应或读取失败不会把已有数值写成零。
- 曝光展示当天 Impressions 总数，合计认证与未认证用户维度。目前没有可靠的主推 / 回复曝光拆分，因此只显示总曝光。

**道侣与飞升**

- 粉丝变化是首次观测后的净变化，无法区分新增与取关，也无法恢复首次观测前的变化。
- 飞升每日净增 = 当日最新官方进度 − 前一天最后一次官方进度。缺少连续基准时，以当天首次观测建立基准并标注，不把跨日差额算作单日增长。
- 90 天滚动窗口可能产生到期扣减或平台校正，负数会保留；这是进度净变化，不等同于当天全部合格曝光。
- 官方页面显示约数时，按其精度记录并标注「约」，不推算不存在的个位数精度。
- 粉丝观测与飞升变化按账号建档时区分日，默认为 **Asia/Shanghai**，与工作室 UTC 日期存在差异。

50W 是面板当前的进度目标，并不代表满足 X 的全部参与或收益条件。资格与奖励规则以 X 当前页面为准；插件不会发放或保证奖励。

## 提醒与运行条件

到时提醒在面板持续显示，并请求高优先级系统通知；面板有过用户交互且浏览器允许音频时，播放提示音。系统通知仍受 Chrome 与操作系统设置影响。

浏览器关闭、系统休眠、后台标签节流、网络或 X 数据延迟都可能推迟同步和提醒，5 分钟是计划周期。X 页面与 GraphQL 字段可能变动；读取失败保留上次数据，需要更新适配器。此项目为非官方工具，与 X 无隶属关系。

## 隐私与权限

数据按账号隔离，保存于本机 `chrome.storage.local`；会话状态使用 `chrome.storage.session`。插件没有云端服务、埋点或第三方 AI 请求。

- 读取当前账号资料、发布事件和创作者数据，不保存帖子正文、私信、Cookie、授权头或 API 密钥。
- 后台页面沿用当前 X 登录态，不提取或转存登录凭据。
- 不自动发推、回复、点赞或关注。
- 帖子元数据保留最多 120 天 / 20,000 条，日快照独立保留。

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存账号、设置与修行记录 |
| `alarms` | 后台同步与撰写提醒 |
| `notifications` | 到时系统通知 |
| `x.com/*`、`twitter.com/*` | 在 X 显示面板、观察发布成功事件和读取本人数据 |

账号验证截图、个人数据记录、安装包与旧设计候选通过 `.gitignore` 留在本地，不纳入源码仓库。

## 开发

需要 Node.js（支持内置 `node --test`，建议 20+）、npm 与 Python 3；无第三方运行依赖。

```sh
npm test           # 数据口径、事件处理、后台同步测试
npm run check      # 重新构建、脚本语法、清单与资源检查
npm run preview    # http://127.0.0.1:4178/demo.html
npm run package    # release/X修仙-v0.1.8.zip
```

演示页使用明确标注的虚构数据，与真实账号存储独立；安装包排除演示页。解压安装包后，加载包含 `manifest.json` 的 `X修仙/` 目录。

`npm run build` 将共享核心与各执行环境脚本组合成独立文件，避免 Chrome MAIN / ISOLATED 环境隔离造成依赖缺失。修改源文件后应重新构建；仓库保留生成文件，方便直接加载。

```text
extension/      插件源码、构建文件、演示页与运行素材
scripts/        构建、检查与打包脚本
tests/          核心规则、页面桥接与后台流程测试
design/         当前选用的原生生图母版与提示词
docs/           设计说明
release/        本地生成的安装包（不提交）
```

视觉素材使用原生生图工具制作，透明 Logo 保留真实 Alpha 通道。见 [设计说明](docs/design.md) 与 [素材索引](design/README.md)。
