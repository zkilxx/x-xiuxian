# 设计与实现

采用深墨绿洞府、青玉进度与淡金细节，标题使用宋体；界面文字、数据和交互均为原生 HTML，山水与 Logo 使用独立图片素材。

## 当前视觉

- 背景 `#0b1a1b`，正文 `#ede7d4`，辅助字 `#a0b0ab`。
- 玉青 `#7fdbb7`，金色 `#e6c587`，回复蓝 `#a7cde4`。
- 圆角方形 Logo 由青玉弯刀与暖白直剑交叠成 X，保留中心负形与少量金色刃缘。
- 标题使用透明刀剑 X，与右侧「修仙」文字并排；浏览器与收起按钮使用完整圆角 Logo。
- 顶部山水保留左侧楼阁、中央群峰、右上月亮与右侧孤峰，头像轻微叠在横幅下沿。

## 布局与交互

默认面板宽 372px，受可用视口约束。首页依次展示山水、身份、导航、每日修行、撰写提醒、曝光与道侣并排卡片、飞升进度。高度随内容收紧，日志与设置在内容区滚动。底部只保留同步状态、工作室入口和一个同步按钮。

收起按钮为 56px，固定填满 iframe；根页面禁止滚动，避免行内元素基线产生溢出。顶部拖动位置保存在本机。计数静默更新，回复成功的绿色 +1 位于原回复按钮上方，提醒与反馈浮层不占布局。

横幅母版为 2172×724；完整金框画面位于 y=72 到 y=632。SVG 使用 `viewBox="0 72 2172 560"` 去除上下空边，按完整画幅等比展示，不使用 `cover` 放大裁掉景物。
