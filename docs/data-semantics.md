## 数据口径

**每日修行与曝光**

- 发推数采用工作室 `TweetCreate + QuoteCreate`，回推数采用 `ReplyCreate`；转帖不计。`Reply` 表示收到的回复，不作为自己发布的回推数。
- 本地发布事件只在 X 确认成功后计数，按帖子 ID 去重；失败、取消不计数。启用插件前或其他设备的发布，由工作室今日统计补齐。
- 工作室数据用于校正总数，不与本地总数直接相加。最近 10 分钟的新发布暂时保留，等待官方统计追上；没有待确认事件时也接受官方向下校正。
- 发布统计与曝光沿用工作室的 **UTC 日期**，北京时间每天 **08:00** 换日；北京时间 00:00–07:59 仍属于工作室前一日。每日修行日期旁显示 UTC，并注明换日时间，避免被误认为同步停留在昨天。历史日数据与近期回填去重；空响应或读取失败不会把已有数值写成零。
- 曝光展示当天 Impressions 总数，合计认证与未认证用户维度。目前没有可靠的主推 / 回复曝光拆分，因此只显示总曝光。

**道侣与飞升**

- 粉丝变化是首次观测后的净变化，无法区分新增与取关，也无法恢复首次观测前的变化。
- 飞升每日净增 = 当日最新官方进度 − 前一天最后一次官方进度。缺少连续基准时，以当天首次观测建立基准并标注，不把跨日差额算作单日增长。
- 90 天滚动窗口可能产生到期扣减或平台校正，负数会保留；这是进度净变化，不等同于当天全部合格曝光。
- 官方页面显示约数时，按其精度记录并标注「约」，不推算不存在的个位数精度。
- 粉丝观测与飞升变化按账号建档时区分日，默认为 **Asia/Shanghai**，与工作室 UTC 日期存在差异。

50W 是面板当前的进度目标，并不代表满足 X 的全部参与或收益条件。资格与奖励规则以 X 当前页面为准；插件不会发放或保证奖励。

## 提醒与运行条件

到时提醒在面板持续显示，并请求高优先级系统通知；面板有过用户交互且浏览器允许音频时，播放提示音。系统通知仍受 Chrome 与操作系统设置影响。

浏览器关闭、系统休眠、后台标签节流、网络或 X 数据延迟都可能推迟同步和提醒，5 分钟是计划周期。X 页面与 GraphQL 字段可能变动；读取失败保留上次数据，需要更新适配器。此项目为非官方工具，与 X 无隶属关系。
